## 桌面原生侧栏复查：升级后仍无法新建（2026-11-09）

用户反馈 v0.7.2 仍出现 #18 的现象，已在正在运行的桌面版原生侧栏复现：点击新建后不显示表单。

- `desktop/node_modules/dsh-remote-ssh/package.json` 为 0.7.2，磁盘客户端 SHA256 与发布构建一致：`2acb8f2003036e3a58a428e711a528a76245857e58b2d88a02ce1628495074ae`。
- 检查运行中按钮所属的 React Workspace 函数，实际内存代码仍为 `const gate = host === void 0 || GATED.has(view) && !live;`。磁盘更新没有替换这个已打开窗口的旧模块。
- 应用重新启动后，同样检查得到 `const gate = busyStatus || gateFor({ host, view, live });`，确认实际窗口已加载新代码。
- 在真实桌面原生侧栏点击连接页新建入口，表单出现名称、主机、端口、用户、认证，以及创建并连接、仅保存、测试连接、取消新建；取消后再从右上角主机菜单新建，表单同样出现。

本次没有创建主机、提交凭据或连接远端。它补充验证了真实桌面原生入口及升级后的模块刷新，不能替代真实 SSH 登录测试。排障建议：升级后完全退出并重新启动桌面应用；仅重开侧栏不能保证刷新客户端模块。不需要手改构建产物或重新发相同代码的版本。
