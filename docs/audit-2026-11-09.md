# 本地检查与修复（2026-11-09）

检查基线：916529e（v0.7.0）。原有测试全部通过，额外检查发现文件发布与同步边界缺陷。本分支修复如下问题，回归测试描述的是修复后应有行为。

| 原问题 | 修复 | 回归覆盖 |
| --- | --- | --- |
| rename 任意失败后先删除目标 | 统一安全 rename；OpenSSH 扩展仅在不支持时降级，不再 unlink 目标 | safety：源不存在、权限拒绝、扩展不支持、文本/二进制/上传发布失败 |
| 提前 EOF 仍发布不完整下载 | 提前 EOF 报错，发布前复核源大小/时间；上传同样检查 | safety：短读、源变化、取消最后一个分块、原文件保留 |
| 下载相对路径越界 | 拒绝父路径、盘符、绝对路径、NUL；解析已有本地祖先的符号链接 | sync：父路径、Windows/UNC、符号链接越界 |
| 相对映射目录忽略 sessionCwd | 保存与加载时基于会话目录解析绝对路径 | safety：相对路径解析 |
| Windows 根路径绕过检查 | 规范化前后识别 drive/UNC/平台根目录 | safety：大小写盘符、任意盘符、UNC、归一化根目录 |
| include 阻止遍历父目录 | 区分目录遍历和文件命中，exclude 继续剪枝 | safety + sync：子目录 JS 文件 |
| uploading 时 requeue 未消费 | 任务结束后消费重排标记，再上传新版本 | sync：真实 watcher 与受控上传时序 |
| 下载混用本地与远端基线 | downloadFile 新增 remoteMtimeMs，mtimeMs 仍为本地时间 | sync：两端时间不同 |
| 暂停/删除/修改映射残留旧任务 | AbortController、去抖/队列/冲突清理；路径或主机变化清空基线 | sync：暂停、冲突清理、删除中途上传与待执行任务 |
| 去抖键未区分会话 | 会话 id 纳入去抖键 | sync：相同映射 id 的两个会话 |
| 两秒容差忽略快速编辑 | 精确比较每端自身的基线时间和大小 | sync：同大小快速编辑冲突 |
| 遍历/状态写入失败被吞掉 | 遍历报错；flush 拒绝并记录错误，队列可恢复 | safety：不存在目录、状态写入失败后恢复 |

验证命令：npm test、npm run check。文件操作回归使用内存 SFTP 验证应用层错误语义；自动同步使用真实临时目录与 chokidar。现有真实 SSH、TCP 转发、SOCKS5 和构建产物 WebSocket 测试保留。

兼容性：不支持覆盖 rename 的 SFTP 服务端现在返回错误并保留原目标；状态格式保持 v1，downloadFile 仅新增 remoteMtimeMs。未修改 UI 或添加运行期依赖。

边界：本地符号链接检查不是对抗并发恶意替换路径的沙箱；源变化检查依赖大小和修改时间，不能识别元信息相同的内容替换。手动 pushAll 仍按显式覆盖处理。尚未用用户真实 SSH 服务器和真实 DSH profile 验收。并发传输到同一目标的互斥、内容哈希校验与更多 UI 性能优化留待后续。
